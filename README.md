# 🐍 Python: aprende practicando

¡Bienvenido/a! En este curso aprenderemos Python paso a paso mediante **ejemplos claros, ejercicios y casos prácticos**. La idea es avanzar desde los fundamentos hasta crear pequeños proyectos que puedas compartir y seguir mejorando.

> 🚧 Este repositorio reúne la ruta de aprendizaje del curso. Los temas y proyectos se irán incorporando progresivamente.

## 🎯 ¿Qué aprenderás?

- Comprender la sintaxis y los conceptos esenciales de Python.
- Resolver problemas con código y buenas prácticas.
- Trabajar con datos, archivos y módulos.
- Crear programas pequeños que conecten lo aprendido con situaciones reales.

## 📚 Temario

1. **Primeros pasos**
   - Instalación de Python y preparación del entorno
   - Uso del intérprete y ejecución de archivos
   - `print()`, comentarios y errores comunes
2. **Fundamentos**
   - Variables y tipos de datos
   - Operadores y conversiones
   - Entrada y salida de información
3. **Control del programa**
   - Condicionales: `if`, `elif` y `else`
   - Bucles: `for` y `while`
   - `break`, `continue` y validación de datos
4. **Colecciones**
   - Listas, tuplas, conjuntos y diccionarios
   - Recorridos, métodos y comprensión de listas
5. **Funciones y organización**
   - Parámetros, argumentos y valores de retorno
   - Alcance de variables
   - Módulos e importaciones
6. **Errores y archivos**
   - Excepciones y manejo de errores
   - Lectura y escritura de archivos
7. **Programación orientada a objetos**
   - Clases, objetos, atributos y métodos
   - Herencia y composición: cuándo utilizarlas
8. **Proyectos prácticos**
   - Calculadora y conversor de unidades
   - Juego de preguntas o de adivinanzas
   - Gestor sencillo de tareas
   - Análisis básico de un archivo de datos

## 🧭 Cómo seguir el curso

1. Revisa los temas en orden y ejecuta los ejemplos en tu equipo.
2. Practica modificando el código y resolviendo ejercicios por tu cuenta.
3. Aplica cada concepto en un proyecto pequeño.
4. Guarda tus avances y vuelve a los temas cuando necesites repasarlos.

## 🛠️ Requisitos

- Python 3 instalado en tu equipo.
- Un editor de código, como [Visual Studio Code](https://code.visualstudio.com/).
- Curiosidad y ganas de practicar. No necesitas experiencia previa.

Comprueba que Python esté disponible desde la terminal:

```bash
python --version
```

En algunos sistemas, el comando puede ser:

```bash
python3 --version
```
